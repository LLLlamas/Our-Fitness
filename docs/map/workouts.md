# Map: Workouts (Train tab)

Exercises, rep counter / hold timer, set editing, live sessions, optional Pilates/Yoga/Stretching sections, cardio logging, Live Activity, exercise MET data, on-device-AI workout suggestions.

> Rows describe current code. **Update the matching row in the same commit as the code it describes** — a stale row is worse than none. Index of all maps: [../../CLAUDE.md](../../CLAUDE.md) → "Find it fast".

| Exercise list (Train tab) | `Features/Workouts/ExercisesCard.swift` — THE one list of every exercise (each once), A→Z, `ProgressRing` header = **reps toward a reps goal** ("N of G reps today / this week" + today's burn). Unset → default from own last ISO week (week = its reps; day = reps per trained day; rounded to the step); no reps last week → "Set a goal", empty ring, never an invented number; first + starts at one step. Card query covers last Monday → now for this. Tests: `RepTargetTests`. `WorkoutsView` order: `LiveSessionCard` → `ExercisesCard` → "Training history" → enabled section cards → "Add a section" → "What do you want to work on?". Row tap → counter or hold timer; clock → `SetHistorySheet`; ⓘ → `ExerciseInfoSheet`. Every NON-isometric row has inline `−1` (`.tactile(.secondary)`) / `+1` (`.tactile(.primary)`), plain text on minute rows too; a11y "Add/Remove 1 rep (minute) of X". **+1** (`quickLog`): new 1-rep/1-minute set via `Repos.setCaloriesEstimate`; a `tracksPerSetWeight` lift is stamped with `RepHistory.lastWeightLb` over full history (`Repos.setHistory(limit: 100_000)`; the card's query holds only today + yesterday; nil = bodyweight) and the toast shows it ("+1 rep · 25 lb", `ProgressFormat.weight`). **−1** (`removeOne` → `Repos.removeOneFromToday`, picks `RepHistory.newestSet`): today's newest set of that exercise — any set — loses one (`updateSet`, re-priced, weight kept) or is deleted at 1; disabled at 0 today; never yesterday; no toast; `Haptics.tap()` on success only. Known limitation: enabled state reads the card's today count, so past midnight −1 can look enabled until refresh (writes nothing). Tests: `RepHistoryTests`, `RemoveOneTodayTests`. Delete: press-and-hold the row body (`simultaneousGesture(LongPressGesture(minimumDuration: 0.5))` on the two row-body buttons → one `confirmationDialog` per row keyed off the single `pendingDelete`, so the iOS 26 popover points at the row; `Haptics.warn()` once; the release tap is ignored) or `SetHistorySheet`. `.swipeActions` is a silent no-op in a `Card`'s VStack.
