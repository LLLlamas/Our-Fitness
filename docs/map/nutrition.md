| Food search (library + ingredient pickers) | `Domain/FoodSearch.swift` → `FoodSearch.combined`. **Matching:** `FoodSearchQuery` folds case/accents/apostrophes (`RestaurantMatcher.words`), maps `spellings` (doughnut→donut, barbecue→bbq…), drops stopwords, matches words in any order — each word prefixes a food word or shares an exact singular form ("donuts" ↔ "donut", never "fries" → "fried"); run-together queries ("chickfila") match run-together names. Curated via `CuratedSearchIndex`; USDA via `SQLiteFoodDatabase.searchAsync(ftsQuery:)` (each word OR'd with forms + variants, words joined with ` AND ` — a bare space before an `(… OR …)` group is an FTS5 syntax error; 60 rows, re-checked with `tier`). **Ranking:** per block by `tier` (0 exact name/alias · 1 prefix · 2 all words in name · 3 via aliases/run-together), then `RegionalChains.rareNearNYC` last, then A–Z. **Chain queries** (`FoodSearch.search` in `Domain/ChainResults.swift`, what `debouncedFoodSearch` runs): when `RestaurantMatcher.split` peels off a chain ("mcdonalds fries"), that chain's items lead; size variants collapse into ONE row (`SizeVariants`; default Medium > Regular > Grande > 10 pc > first) with the other sizes as pills in `FoodResultRow`, max 5 groups; the chain's `ff-` rows drop when `rest:` rows exist; other chains drop; other rows capped at 5 (uncapped when the menu has no hit, e.g. "ghost pepper"); a usda row whose name words are all chain words (bare "Mcdonald's") drops when the menu matched. `FoodSearchOutcome.strength` (`MatchStrength`; strong = menu hit or top food at `tier` ≤ 1): strong → the describe card becomes a compact "Or log … as a meal" link below the list, else it leads. **Typos (deterministic):** `editDistance` (adjacent swap = 1 edit); `split` accepts a leading word (≥ 5 chars, run together) one edit from exactly one chain key unless it is a food word (`nonChainWords` + curated words: cakes/canes, queso/quest, panela/panera…); `SearchVocabulary` (curated names + aliases, menu-item words, chain keys; built in `CuratedSearchIndex`) replaces a ≥ 5-char word that matches nothing with the one word one edit away (most frequent wins), never while a valid prefix is typed; in a chain query the remainder is fixed against THAT menu first (`menuCorrection`: "fires" → Fries); `RestaurantMatcher.filter` uses `FoodSearchQuery.hits` (plural forms). `FoodSearchOutcome.correctedQuery` → "Showing results for …". **Did you mean:** `Services/FoodQueryRewriteService.swift` proposes ≤ 3 queries (`FoodSearch.cleanSuggestions`), each kept only if `FoodSearch.search` finds food; pills under "Showing results for", once per query — on submit when results aren't strong, and after a 1.2 s pause when weak or empty (not for a multi-food sentence, never for a tapped suggestion); nothing when Apple Intelligence is off. Tests: `FoodSearchTests`, `ChainResultsTests`, `RestaurantCatalogTests`, `FoodSearchRealDataTests` (real `usda-foods.db`) |

| Add food (search + describe, one sheet) | `Features/Nutrition/AddFoodSheet.swift` — THE food-search/log sheet: one field pinned above the scroll area. **Empty = My Foods** (`FoodAffinity.myFoodsSections`, pure, tested; each food once on screen, identity = foodId else lowercased name, later sections take the next in line): Favorites (≤ 8, A–Z pills; long-press = Remove from favorites) · Recent (≤ 8, newest first, one bordered list of compact rows — name + portion label when ≠ ×1, then "cal · g pro · today / yesterday / Mon, Nov 17" — with a heart when the entry is one known food; reopens at that portion via `FoodLogEntryDTO.repeatIngredients`; the box is as tall as its rows up to 85% of the visible area via `containerRelativeFrame` (runs to the bottom of the screen), scrolling on its own with a flashed indicator only when the rows don't fit, e.g. keyboard up; the page still scrolls to the sections below) · Recipes & my foods (≤ 8 templates, newest first); plus "Enter numbers manually" and, for a new user, "Tap ♥ on a food to keep it here". No "Most logged" row, no full-library list, no Restaurants UI (chains are reached by typing). Favorites = `@AppStorage` `favoriteFoodIds.<uid>` via `FoodFavorites`; resolve curated (`CommonFoods.byId`) → own logs (`FoodAffinity.loggedFoods`) → `SQLiteFoodDatabase.entries(ids:)` (async; no id index, a table scan — once per unresolved set). **Typed:** "Log ‘…’" describe card → `DescribeMealForm` (AI/full-DB parse + manual macros; also `CameraFoodLogSheet`'s fallback — the ONE free-text logger) + results via `View.debouncedFoodSearch` / `FoodResultRow` (shared with `IngredientFoodSearchSheet`); matching templates (`FoodAffinity.matchingTemplates`) list under "My Foods" above Foods. **Save to My Foods:** toggle in manual entry; after the log write returns true, `Repos.addSavedTemplate(SavedMealTemplateDTO.singleFood)` (a failed second write = warn toast, never success). Picks (incl. `MoodMealSheet` ideas) confirm in `MealIngredientDetailSheet`. `onSave` returns the write's success; dismiss only on `true` (rule 9). The Meals empty state has no button of its own |
| Restaurant / chain menus | Data: `scripts/restaurant-data/<slug>.json`, one per chain, numbers ONLY from the chain's own published nutrition (official page/PDF/calculator, or the Nutritionix menu its site links), five nutrients only (never sodium/sugar/sat fat — see `capCoverage`). Merge: `python3 scripts/build-food-db.py --merge-restaurants-into OurFitness/Resources/usda-foods.db` (idempotent; `rest:<slug>:<item>` rows in `foods` + `restaurant_chains` / `restaurant_items`); drops limited-time rows, exact duplicates and rows whose 4P+4C+9F contradicts the calories (`_broken_row`; alcohol exempt) — source typos are dropped, never corrected. Swift: `Domain/RestaurantCatalog.swift` (`RestaurantMatcher.split` / `filter`; `menuMatches` is test-facing), loaded once, arranged by `ChainResults`. Same folder holds sports-nutrition brands (`"kind": "supplement"`, from each brand's label — USDA Branded lacks most). Every file re-audited against its source Oct 2026; a new file needs the same check. Skipped for lack of usable official data (Oct 2026): Burger King, Sonic, Jack in the Box, Smashburger, MOD Pizza, Jason's Deli, Wawa, Cracker Barrel; Muscle Milk, Garden of Life Sport.
